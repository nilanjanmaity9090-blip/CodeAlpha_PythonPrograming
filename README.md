# CodeAlpha Python Programming Internship

This repository contains three beginner-level Python projects completed for the CodeAlpha Python Programming internship tasks.

## Projects
1. **Hangman Game** (`Task1_Hangman_Game/hangman.py`) — a console word-guessing game with five predefined words and a maximum of six incorrect guesses.
2. **Stock Portfolio Tracker** (`Task2_Stock_Portfolio_Tracker/stock_tracker.py`) — calculates investment from a hardcoded stock-price dictionary and can save a summary to `portfolio.txt`.
3. **Basic Chatbot** (`Task3_Basic_Chatbot/chatbot.py`) — a rule-based chatbot using functions, conditions, and a loop.

## Requirements
- Python 3.8 or later
- No external libraries are required.

## How to run
Open a terminal in this repository folder and run one command at a time:

```bash
python Task1_Hangman_Game/hangman.py
python Task2_Stock_Portfolio_Tracker/stock_tracker.py
python Task3_Basic_Chatbot/chatbot.py
```

On some systems, use `python3` instead of `python`.

## Notes
- Stock prices are hardcoded sample values for this programming exercise. They are not live market prices.
- The stock tracker creates `portfolio.txt` in the current working directory if you choose to save the summary.
